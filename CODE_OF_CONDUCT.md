# Code of Conduct

This project follows the spirit of the
[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

- Be respectful and constructive; critique code and ideas, not people.
- No harassment, discrimination, personal attacks, or publishing others'
  private information.
- Assume good faith, and keep discussion on topic.

Maintainers may edit or remove comments, commits, issues and pull requests
that violate this, and may block repeat offenders. Report problems privately
to the maintainer through GitHub (`geoffreypboals-web`); reports are kept
confidential.
